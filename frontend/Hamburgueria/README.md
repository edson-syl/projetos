# 🍔 BurgerTop — Sistema de Presença Digital para Hamburguerias

Um site moderno e otimizado para **aumentar pedidos via WhatsApp**, desenvolvido com foco em **conversão, performance e experiência do usuário**.

---

## 🎯 Objetivo

Ajudar hamburguerias e pequenos negócios a:

* 📈 Aumentar pedidos online
* 📲 Centralizar atendimento no WhatsApp
* ⚡ Melhorar a presença digital
* 💰 Converter mais visitantes em clientes

---

## 🛠️ Tecnologias Utilizadas

* **React.js**
* **Tailwind CSS**
