# 🍔 Cardápio Digital com QR Code

Um sistema simples, rápido e eficiente para restaurantes e lanchonetes receberem pedidos diretamente pelo celular dos clientes.

---

## 🚀 Sobre o projeto

Este projeto permite que clientes:

* 📱 Escaneiem um QR Code na mesa
* 📖 Visualizem o cardápio digital
* 🛒 Adicionem produtos ao carrinho
* 📲 Enviem o pedido diretamente para o WhatsApp do estabelecimento

Tudo isso sem precisar instalar aplicativos.

---

## ⚙️ Funcionalidades

✅ Cardápio digital moderno

✅ Carrinho de compras funcional

✅ Controle de quantidade de itens

✅ Cálculo automático do total

✅ Identificação por mesa via QR Code

✅ Envio de pedidos direto para o WhatsApp

✅ Interface responsiva e intuitiva

---

## 🧠 Como funciona

1. Cada mesa possui um QR Code
2. O cliente escaneia o código
3. O sistema identifica automaticamente a mesa (ex: `?mesa=5`)
4. O cliente escolhe os produtos
5. Ao finalizar, o pedido é enviado para o WhatsApp com:

   * Lista de itens
   * Quantidade
   * Total
   * Número da mesa
