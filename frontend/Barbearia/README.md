# 💈 Barbearia - Website

Um site moderno e responsivo para barbearia, desenvolvido com foco em experiência do usuário, organização de conteúdo e conversão de clientes.

---

## 🚀 Sobre o projeto

Este projeto representa o site institucional de uma barbearia, com seções bem definidas que apresentam serviços, informações da empresa, galeria de trabalhos, depoimentos de clientes e formas de contato.

A ideia é oferecer uma navegação fluida e visualmente atraente.

---

## 🛠️ Tecnologias utilizadas

- React.js  
- JavaScript (ES6+)  
- CSS
- Componentização para organização e reutilização  

---

## 📱 Responsividade

O site foi desenvolvido para funcionar bem em:

- 📱 Dispositivos móveis  
- 💻 Tablets  
- 🖥️ Desktop
